# AIEO Basic 最终验收清单（初级版 v0.1，随 WORKFLOW v0.3）

> **生效状态（正式版）：** 本清单为正式版，已随 WORKFLOW.md v0.3 于 2026-11-15 经用户拍板**正式生效**；批准依据与记录位置见 WORKFLOW.md v0.3 生效状态 blockquote。
> **用途与分工（拍板要点 5）：** 任务包检查器（`basic/tool/check_taskpack.py`）查**结构性、格式性有限规则**（可自动化：字段非空、SHA 格式、返工关联等）；本清单查**完整工程质量**（需人工判断——六要素"存在"≠"真实准确"）。两者互补，检查器 PASS≠本清单通过，本清单通过前仍须跑检查器终检。
> **三态判定：** 每项结论 = **PASS / FAIL / N/A**。N/A 必须注明明确适用条件（该条为何不适用于本任务），**不得以 N/A 绕过必检项**——适用条件不成立才算 N/A，条件存在但未做 = FAIL。
> **整体通过条件：** 全部必检项 PASS（N/A 项须条件成立且已注明）。**不以通过数量/百分比代替**（1 项 FAIL 即整体不通过）。
> **BLOCKED 边界：** BLOCKED 是**任务级验收阻断状态**（WORKFLOW 模块四），不是本清单的第四种项目判定状态。因环境原因无法完成某项检查时，**不得**将该项标 N/A 或 PASS——如实记录阻断原因，任务整体维持 BLOCKED，解除后继续检查。
> **来源：** 阶段 C 统计（b-20261115-phasec-workflow-stats）ST-01~ST-12；条目依据统计发现与实测先例制定，标注 [ST-xx] 者直接对应统计追踪项。
