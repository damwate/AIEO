## 场景清单（冻结候选，依 R1 裁定重构）

### ① 多 assistant unit 采集全链（R1：有条件保留）

- **两道独立判断：** 触发有效性＝同一真实会话自然产生的≥2 个独立 assistant unit（禁止 DOM 复制/人工拆分/测试 fixture 充数）；采集有效性＝unit_count≥2、unit key 顺序连续、区间起止完整、全文稳定、UUID 一致、原始 artifact 回读与 SHA256 一致、登记成功。
- **特殊裁定（R1 原文口径）：** 模型未产生多 unit→BLOCKED（不判采集器失败）；模型产生多 unit 但采集器遗漏或无法证明完整→REWORK/BLOCKED（按具体故障归因）。
- **次数上限（R2 补充细化）：** 一次真实尝试＋一次备用触发策略（仅可触发一次）：主策略=简报显式请求"分多条独立消息回复"；备用触发条件=主尝试后未形成有效多 unit 且会话状态可确认（非不确定态）时，改用更强显式指令（预设："请将回复拆成编号段，每段单独成一条消息"）重试一次；备用仍未形成有效多 unit→结束为 BLOCKED；不得向不确定状态的会话重复发送；不得把人工拼接的 unit 作为备用成功样本；不得无限重试或反复消耗真实审查会话。

### ④-A 死会话派单层闭环（R1：纳入本批；对象=AIEO gpt_dispatch 派单层）

- 方法：建一次性会话→记录独立身份→删除该一次性会话→仅向其派单→观察页面就绪失败/死页识别。
- 断言：无错误成功登记、无误更新审查会话指针、无重复发送、退出清理正常、错误现场留存。
- 判定重点＝派单层**安全失败**（不是是否执行梯子）。

### ④-B 限时断网派单层（R1：纳入本批；对象=AIEO gpt_dispatch 派单层）

- 隔离约束（R1 原文口径）：仅无在途派单时开始；仅针对本次一次性测试对象；事先限定断网窗口与恢复时点；网络恢复后先检查状态再决定后续操作；不得反复断网制造更多失败样本。
- 断言：断网期间无虚假成功、无未授权重发。

### ⑤ 多文件部分读取失败（R1：有条件保留，最适确定性注入）

- 材料：A 正常文件（能读取校验）/B 不存在返回 404（整体失败）/C 存在但 SHA 不符（整体失败）。
- 补充断言（R1 原文口径）：不允许只返回 A 的部分成功；不允许把 A 内容写入最终成功登记；B、C 失败原因分别可辨认；不允许自动切换 branch HEAD 或其他 commit 兜底；失败现场保留，临时登记条目在证据完整归档后清理（不涉真实登记簿与他任务条目）。
- 验收核心＝**整个多文件事务的 fail-closed**，不是仅证明两个文件读取异常。
