**关键原则（审查方原话）**：前端结构 PASS ≠ 业务数据展示 PASS。缺数据展示位可留空，但不得宣称完整验收 PASS。

## 二、三态数据展示门禁（新增，审查方裁定）

| 状态 | 含义 | 验收 |
|---|---|---|
| VERIFIED | 数据来源及映射已验证 | PASS |
| MISSING | 数据源尚未提供 | 条件性 PASS（展示位留空） |
| INVALID | 数据存在但错误/冲突/格式异常 | FAIL（不得静默当 MISSING） |

留空六条禁令：不固定默认值伪造；不用合同级整装标识推行级；不按商品名猜单位；不反推草皮长宽厚度；不混淆 0/空串/null；空字段不影响其他有效字段展示。合法 0 不得被当空隐藏（A16）。
