# P1 批次复盘模板（b-20261119-multitask-p1-execution，七项前置核验⑦）

- **性质：** P1HANDOFF-R1 七项前置核验⑦落地文件（2026-11-20）。单任务复盘=每审计任务验收后填 A 表；批次总复盘=P1-02 验收后填 B 表并据以生成 P1 阶段收口记录（S7 权威状态源更新）。

## A. 单任务复盘（每任务一份，登记于该任务 delivery.md「批次复盘」节）

1. **身份与授权链：** task_id；授权依据（资格审查冻结+P1HANDOFF-R1 序号）；被测对象完整 SHA。
2. **执行形态：** 独立审查会话 UUID；派单简报标记与字节；发送双验/采集方式（直采/补采）。
3. **裁定结果：** 审查问题逐项裁定（PASS/FAIL/BLOCKED+理由）；reply SHA256。
4. **证据闭环：** 五件套逐文件存在+非空+SHA256 清单；acceptance/ 归档清单。
5. **边界遵守：** 排除项逐条核对（不重跑/不重复计数/不冒充⑥）；零代码/零 M1/零 DEC-010 声明。
6. **问题与经验：** 本任务遇到的问题与处置（对照 AI-DEV-LESSONS 条目，新经验提议入库存档）；熔断触发记录（如有）。
7. **遗留与归属：** 未解决问题清单+每项归属（下一任务/另立任务/交用户）。

## B. 批次总复盘（P1-01+P1-02 验收后，登记于本任务包 delivery.md）

1. **两任务结果对照：** P1-01/P1-02 裁定摘要并排；两审计 PASS/FAIL 与 906⑥ 状态的隔离声明（两任务 PASS ≠ 906⑥ PASS）。
2. **原要求对照：** 逐条对照 MULTITASK-IMPLEMENTATION-PLAN §六 P1 范围——达成/降级/未达，降级理由引用已登记最小方案（handoff 总结 §三）。
3. **七项核验执行回顾：** 核验记录与实际执行的偏差（如有），偏差处置登记。
4. **通道纪律回顾：** FIFO 执行实况、会话隔离实况（两审计会话 UUID 并排）、fail-closed/补采发生记录。
5. **熔断与异常：** 本批熔断触发/解除记录（无则声明无）。
6. **P1 阶段结论：** P1 是否达到收口条件；906⑥ 门状态重申（BLOCKED，实测另批）；P2/P3 未授权重申。
7. **下一步建议：** 交用户/交下一会话的建议清单（含 PHASE-STATUS 更新内容要点，供 S7 执行）。
