R4 付费接口测试方法审议。背景：生图/付费 API 参数验证曾用真实调用矩阵+生产冒烟，产生费用；用户明确要求先官方文档、禁黑盒/冒烟，真实数据须先获同意。请只讨论方法，不调用真实接口。请给可执行方案：
1) 官方文档/版本/供应商差异如何取证，文档缺失或冲突时禁止哪些推断；
2) 本地 mock 契约测试如何证明出站 size/params/参考图、配置覆盖链、重试与旧任务兼容；
3) 不经生成的只读验证（账单/配额/模型目录/日志）边界；
4) 唯一一次付费验收的前置条件、用户授权内容、成本控制与失败即停；
5) 输出测试分层、发布门禁及最小测试清单，区分“参数被接受/输出符合/实际计费”三种证据。
