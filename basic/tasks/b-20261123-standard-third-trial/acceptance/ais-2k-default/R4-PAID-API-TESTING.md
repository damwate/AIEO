## 四阶段门禁

1. **L0 官方契约**：分供应商/模型/通道记录官方文档、版本、参数、价格；文档冲突或缺失=UNKNOWN，不得推断。
2. **L1/L2 配置与本地 Mock**：在最终 HTTP Transport 边界截获请求，验证 size/params/图片字节/覆盖优先级/重试/旧任务兼容，零费用。
3. **L3 只读证据**：模型目录、配额、历史账单、历史日志；只读结果不得反推未来生成能力。
4. **L4 授权付费验收**：提交具体供应商/模型/通道/size/输入图片/费用与上限/重试策略授权单，用户明确批准后执行；失败即停，不自动重试或 failover 再扣费。发布后只做只读监控。

## 三种证据分开

- `PARAMETER_ACCEPTED`：接口接受请求；
- `OUTPUT_CONFORMED`：输出尺寸/格式符合；
- `BILLING_CONFIRMED`：账单或供应商用量明细确认计费。
三者不得互相替代。HTTP 200 不等于输出符合，输出 2048×2048 不等于按 2K 档位计费。

## 用户补充（同日，优先级高于对规则的机械理解）

不是禁止真实测试，也不是简单参数测试就有意义：
- 接口开发之初可经授权做完整业务链路全量测试；
- 后续每次变更按影响面选择有业务意义的目标测试，不做付费全量矩阵；
- 不用孤立 size 参数探测代替产品外观、占比、原图参与、最终生图质量等业务效果验收。
