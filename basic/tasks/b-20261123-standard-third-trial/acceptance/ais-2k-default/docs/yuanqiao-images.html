远桥云图片生成 API 接入说明

图片生成

远桥云当前提供以下图片能力：

  • image2 / image2.5 图片能力使用 Images API。现有 image2 / image2.5 分组使用 gpt-image-2；GPT Image 2.5 的远桥云模型 ID 为 gpt-image-2.5-flare 或 gpt-image-2.5-sunburst。
  • Gemini 图片模型使用 Gemini 原生 generateContent 接口，也可以使用 OpenAI 兼容的 Chat Completions 接口。

不同模型的请求和返回结构不同。请先按模型选择正确的 endpoint，不要把图片模型直接当作普通聊天模型调用。

文生图

POST /v1/images/generations

此接口用于 gpt-image-2（包括 image2 / image2.5 / image2.6 图片能力）与 Grok 图片模型（grok-imagine-image、grok-imagine-image-2.0、grok-imagine-image-quality）。Gemini 图片模型不要发送到此 endpoint。

请求参数

字段类型必填默认值当前网关行为
modelstring是无填写令牌所属分组开放的模型名：gpt-image-2、gpt-image-2.5-flare 或 gpt-image-2.5-sunburst。
promptstring是无图片提示词。
sizestring否由所选模型决定使用 宽x高，例如 1024x1024。只使用小写字母 x，不要使用乘号 ×。
ninteger否1网关接受 1 到 128；为便于排查与控制费用，建议先使用 1。最终图片数量以响应 data 为准。
qualitystring否auto 或由所选模型决定GPT Image 2.5 支持 auto、low、medium、high、xhigh、max；其他模型按该模型支持的质量设置处理。不要把 1K、2K 或 4K 写入此字段。尺寸统一通过 size 表达。
response_formatstring否由所选模型决定原样传递。客户端必须同时处理 data[].url 与 data[].b64_json 两种返回字段。

Images API 当前不使用 aspect_ratio。需要横图、竖图或方图时，请通过 size 指定宽高比。image2 / image2.5 以及 GPT Image 2.5 Flare / Sunburst 都使用 宽x高 表达尺寸，不要把 1K、2K 或 4K 直接写进 quality。

参考图片编辑

使用 POST /v1/images/edits，JSON 请求，单图放在 image 字段。图片必须是带类型前缀的 Base64，例如 data:image/png;base64,...；不能填写本机文件路径。多图编辑暂未纳入公开接入范围。

参考图的格式与限制以接口响应为准。需要多张参考图时，先确认当前模型和令牌是否支持，再逐步增加。

Grok 图片模型与 Grok 视频模型是不同能力：图片使用 /v1/images/generations 与 /v1/images/edits，视频使用 /v1/videos/generations，两者的模型名不能互换。

Gemini 图片模型

Gemini 图片模型可以使用原生 generateContent，也可以使用 OpenAI 兼容的 chat/completions。两种方式都使用 generationConfig.responseModalities 请求图片，不走 Images API 的 data[] 结构。

原生接口的尺寸通过 generationConfig.imageConfig.imageSize 指定，可填写 "1K"、"2K" 或 "4K"；比例通过 aspectRatio 指定。图片内容位于响应的 candidates[].content.parts[].inlineData.data，并且应按 inlineData.mimeType 选择保存扩展名。

OpenAI 兼容 Chat Completions

兼容接口中的 image_config 使用下划线字段名：image_size 可填写 "1K"、"2K" 或 "4K"。响应图片通常位于 choices[0].message.content 中的 data:image/... 内容；客户端应兼容字符串和 parts 数组两种形式。

gemini-nano-banana-2.1

gemini-nano-banana-2.1 与上面的 Gemini 图片模型使用同一套接口，替换模型名即可。原生接口返回的图片位于 candidates[0].content.parts[].inlineData.data；OpenAI 兼容接口需要 stream: false，图片位于 choices[0].message.content 的 data:image/... 中。

参考图编辑同样通过 contents[].parts[] 传入：文字放一个 text part，每张参考图放一个 inline_data part（mime_type 加 Base64 data）。使用 /v1/chat/completions 时，参考图放 image_url part：

Gemini 图片模型不属于 POST /v1/images/generations。把它们发送到 Images API 会因 endpoint 与模型不匹配而失败。

为了避免一次请求产生多张图片和对应费用，生产接入建议始终从 n: 1 开始。不要把横竖比例写成 aspect_ratio 并发送到 Images API。

请求大小与上传限制

api.yuanqiaoyun.com 当前反向代理的 client_max_body_size 为 110 MB；New API 应用层的 MAX_REQUEST_BODY_MB 默认值为 128 MB。因此生产环境的有效上限是 110 MB。multipart/form-data 中的所有字段和文件都计入该大小。

客户端或后续网络链路也可能设置更低的限制。因此：

  • 上传前先压缩或缩小参考图。
  • 不要把大图片先转为 Base64 再塞进 JSON。
  • 收到 413 时，表示 HTTP 请求体过大，不是模型上下文 Token 超限。
  • 单图编辑从一张体积较小的 PNG、JPEG 或 WebP 文件开始验证。

常见错误

HTTP 状态常见原因排查方式
400缺少 model、prompt、编辑接口的 image，或 size 格式错误。确认 JSON / multipart 字段和 endpoint；size 使用小写 x。
401API Key 缺失、无效或未带 Bearer 前缀。检查 Authorization: Bearer sk-your-api-key。
403API Key 没有目标模型所属分组权限，或请求未通过内容审核。在模型广场核对模型和分组；读取响应 error。
413HTTP 请求体超过限制。缩小上传图片；不要用 Base64 扩大请求体。
429请求触发远桥云接口限流，或服务繁忙。降低并发，采用退避重试。
5xx图片请求处理失败或服务暂不可用。记录 HTTP status、响应 body 和请求 ID 后重试。

内容安全

图片提示词和参考图都会经过内容安全审核。色情、裸露、涉及未成年人不当内容、极端血腥暴力等请求可能被拒绝。图生图时，输入图片本身也可能触发审核。

请避免在提示词中堆叠大量敏感词或试图绕过审核。收到审核拒绝时，不应仅通过重复提交同一请求来重试。

调试建议

  1. 先用 gpt-image-2、1024x1024、n: 1 和纯文本 prompt 验证文生图。
  2. 确认模型名和 endpoint 配对：gpt-image-2（image2 / image2.5）使用 Images API，Gemini 图片模型使用 generateContent 或 Chat Completions。
  3. 文生图使用 application/json；编辑使用 multipart/form-data，不要手动指定 multipart boundary。
  4. 编辑时先上传一张小图片，确认 image 字段和文件名正确。
  5. 同时处理 data[].url 与 data[].b64_json，不要只按一种返回格式解析。
  6. 发生错误时保留 HTTP status、响应 body 与请求 ID，便于定位参数、权限或服务问题。

Playground 与图片 API 的区别

Playground 是交互界面；选择某个图片模型并不代表客户端会自动调用 POST /v1/images/generations。

  • gpt-image-2 的标准客户端文生图使用 POST /v1/images/generations，编辑使用 POST /v1/images/edits。
  • Gemini 图片模型使用 POST /v1beta/models/{model}:generateContent。
  • Chat Completions、Responses 和 Images API 的请求体、返回结构与计费路径不同，不能只替换模型名后混用。

当前未开放为图片 API 文档能力

以下能力未纳入当前公开接入承诺：异步图片任务、mask 编辑、多图编辑、ComfyUI 专项配置，以及未发布的 quality 或 aspect_ratio 枚举。请不要把其他平台的专有字段直接混入远桥云请求；如需额外能力，请先确认当前模型和令牌是否支持。
