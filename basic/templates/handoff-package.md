# 交接包（Basic 场景指引）

- **唯一权威模板：`docs/phase1/handoff-template.md`（v0.3）**——本文件不设副本，直接按权威模板填写，避免双份维护（"引用不复制"原则同样适用于模板）。
- Basic 场景必填要点：
  1. §1"任务版本选型"三行（选定版本 / 任务等级 / 选型理由 + 批准人日期）——不可留空；
  2. 依据：commit SHA、证据路径；
  3. 派单证据：dispatch 日志目录 + reply SHA256；
  4. 遗留项与下一步。
- 存放位置：任务内 `tasks/<任务ID>/handoff.md`；全局交接放仓库根 `handoff/`。
