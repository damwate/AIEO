## 与 Basic 的关系

Basic（`../basic/`）开发时**可直接从中级版资产复制初级功能**出来用（用户 2026-11-14 指示）；复制不得改动中级版资产本体。公共工具（派单、体检、推送）仍按"引用不复制"引用 `phase0/tools/` 与 `toolkit/`。
