## 5. 三红线与退出机制（DEC-096 明示）

1. **等级 B ≠ 无人值守**：人类保留关键决策权与最终批准权；每批放行、扩围、异常处置均需 ChatGPT 复审+用户授权链。
2. **试运行 ≠ 扩大权限**：不因四腿交付闭环就默认可自主执行所有操作；写操作需单独授权。
3. **试运行 ≠ 无限期试验**：须有明确成功/停止/退出标准——
   - **成功标准**：首批 2 任务全部满足五件套验收、零 P0、零越权、零证据失真、零角色串位。
   - **停止条件**：§3 五类失败即停任一触发；或阶段复盘判定可靠性不达标。
   - **退出机制（规划复审裁定：三分法闭环，暂停不得自动视为恢复授权）**：
     - **(a) 正常结束**：阶段复盘完成 → ChatGPT 复审决定是否扩围进入下一批；906 顺延仅在扩围且用户授权后另行启动。
     - **(b) 暂停整改**：修复缺陷 → 独立验收通过 → **重新申请**恢复（不自动恢复授权）→ ChatGPT 复审决定重跑首批或进入下一批。
     - **(c) 终止试运行**：保留全部证据 → 回退试运行状态（登记终止结论与原因）→ 不得在无新 Gate 授权下重启。
