# AIEO 可行性风险与未验证假设登记（FEASIBILITY-REGISTER）

**版本：** v0.3【T-P1-905 D1′ 执行后更新：F-002 补证据收窄缺口、F-004/F-007 转 VERIFIED；全文仍待用户审阅定稿（TECHNICALLY_PASSED 级，未 USER_REVIEWED）】
**定位：** 项目全部未验证技术假设与可行性风险的单一登记处（EXP-PLANNING-001 §五）；每会话发现新问题**先登记、评估，不得无边界扩展当前任务**（§二.5）。
**纪律：** 每项必须含假设内容、当前证据、缺口、风险等级、验证路径与状态；关闭一项须附证据并记版本；"已验证假设区"保留成果防止重复开发（§八）。
**初始化依据：** 复盘盘点 `docs/reviews/2026-11-14-总体规划与可行性复盘-主会话盘点.md` 议题 2/5/6；DEC-017/DEC-021 边界。

**风险等级定义：** 高=直接威胁十步闭环目标或项目命门；中=影响 MVP 验收完整度或效率；低=局部影响。
**状态定义：** OPEN=未验证待验证路径；OPEN-DEFERRED=已裁定暂缓（有明确恢复条件）；VERIFIED=已验证（附证据）；INVALIDATED=被证伪（附原因与决策）。

## 1. 未验证假设（OPEN）

### F-001 中央调度引擎未工程化
- **假设/现状：** 立项架构图最核心的 CORE 节点（需求→批次→拆解→派单→监控→状态机推进）没有模块归属、没有实现条目、没有排期；当前=人工+主会话工具（`phase0/tools/gpt_dispatch.mjs` 手动派单）。
- **当前证据：** 盘点议题 2（2026-11-14 实查）；`docs/phase1/module-boundaries.md` 四模块职责中无调度引擎条目。
- **风险：** 高——MVP"任务能够被可靠派发"（06 §9-2）的承载者缺位；D1′ 前可由人工+主会话顶替，Phase 4 多角色前必须工程化。
- **验证路径：** D1′ 以最小形态人工编排走通全链并记录派单动作清单 → Phase 4 前立项工程化任务（归属 M1 或独立模块，届时拍板）。
- **状态：** OPEN

### F-002 真实网页 GPT 多角色收发（全项目命门前提）
- **假设：** "网页自动化能否稳定支撑真实开发闭环"。
- **当前证据：** Phase 0 POC 单点证据（单 unit、稳定 DOM、公开仓库，DEC-017 允许范围；gpt_roundtrip + 真实派单提取）；M2 实现完整（28 源码文件）但验收为**浏览器模拟级**（`phase1/logs/m2-gpt-controller-20261113/browser_simulation-*`）；**T-P1-905 D1′ 新增（2026-11-14）：真实 chatgpt.com 单角色（GPT-01）单轮业务收发全链 PASS——出站 826 字节、真实回复 1636 字节（assistant UUID `944f5ad1`，双读稳定性 10/10）、经 904 冻结 Schema 双验证后 M1 登记成功（`phase1/logs/t-p1-905-d1prime-20261114/RUN-RECORD.md` §3 步 2–4b）。**
- **缺口（D1′ 后收窄）：** 真实 chatgpt.com **多角色（GPT-03 审查等）多轮**收发仍未进入业务链；单角色单轮已证。
- **风险：** 高——十步闭环 5 个节点依赖此腿；模拟级证据不构成真实链路验收（🔶 CLAIMED_ONLY 边界）；D1′ 后风险降级为多角色扩展面。
- **验证路径：** D1′ 真实规划会话（DEC-017 边界内：公开仓库/单 unit/稳定 DOM/fail-closed）→ Phase 4 逐角色扩展；扩展场景（多 assistant unit/动态裁切恢复等）随 T-P1-906 分批复审。
- **状态：** OPEN

### F-003 测试执行 Worker 缺位
- **假设/现状：** 立项架构有 TEST 节点；M1 只做 test_reports **登记**，测试的真实执行与日志证据采集无人负责。
- **当前证据：** 盘点议题 2；PHASE-STATUS §2.3"测试日志可追溯 ❌"。
- **风险：** 高——"审查和测试有真实证据"（06 §9-4）的测试半边缺位；GPT-04 检查真实测试证据（§7）被其牵制。
- **验证路径：** D1′ 通过后立项最小测试执行 Worker（真实执行+日志采集+登记），归属 M4 或独立，届时拍板。
- **状态：** OPEN
