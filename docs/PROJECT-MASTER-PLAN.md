## 1. 项目最终目标

**一句话目标（单源：`docs/立项/01-总体架构设计.md` §1，自立项未漂移）：** 用户只需提交开发需求，系统即可自动完成十步闭环——GPT 规划 → 架构审核 → 调度 → 智谱开发 → Git 提交 → GPT 审查 → 测试验收 → 总审计 → 用户审批。

**成功标准（单源：`docs/立项/06-MVP实施计划与验收标准.md` §9）：** 不是"AI 能自动写代码"，而是需求可拆解、任务可靠派发、结果可在 Git 定位、审查测试有真实证据、可返工、进度准确、人工可随时介入、全程可追溯复现。

## 2. 总体架构

**单源：`docs/立项/01-总体架构设计.md`（架构图与十步闭环节点）；模块职责边界：`docs/phase1/module-boundaries.md`；平台公共契约：`docs/phase1/platform-contract-v1.0.md`（C1-C8 v1.0.0 已冻结并经用户追认，DEC-011/DEC-018）。**

四模块映射：M1 中央基座 `app/platform` / M2 GPT 控制 `app/gpt_controller` / M3 ZCode 桥 `app/zcode_bridge` / M4 Git Worker `app/git_worker`。

**已确认的架构三缺口（登记于 FEASIBILITY-REGISTER，不在本节展开）：** ①中央调度引擎未工程化（F-001）；②测试执行 Worker 缺位（F-003）；③管理后台仅雏形（F-005）。三缺口是复盘最重要发现（先细节后前提）的架构面投影，处置见 §3 重排路线。

## 5. 治理体系

- **三级项目管理体系（EXP-PLANNING-001 §三）：** 总体规划=用户批准；AI 总体规划顾问（ChatGPT 会务）=全局分析/路线评估/独立复核，**审查意见不等于项目变更授权**（§六）；AI 执行者=按授权完成具体任务，不越权。
- **契约体系：** 平台公共契约 C1-C8 v1.0.0 冻结（DEC-011）；契约冻结文本不修改；机器化按 §10 授权范围落地（DEC-021）；变更走统一变更申请并更新兼容矩阵。
- **决策日志：** DEC-001~021 已登记（`docs/phase1/decision-log.md`），含 Git 规则（DEC-010：合并 main 与发布必须人工审批）、BLOCKED-1 边界（DEC-017：扩展场景逐项验收，未解除）。
- **审查仪式分档（2026-11-14 原则批准）：** 对象身份门禁保留（便宜有效）；分片聚合包仪式仅在材料超出审查环境能力时启用。
- **复评机制（EXP-PLANNING-001 §四）：** 七种触发情形；复评五态 CONTINUE/ADJUST/REPLAN/REJECT/BLOCKED；重大调整须用户批准并登记 decision-log。
