# 标准版任务管理验收基线

基线提交 `fc7da579460800e2f1f74f099825325dfe7d05be`。用户授权实现下列五项。第二轮试运行沿用其原有版本。以下验收分为隔离环境验证和阶段放行，真实三任务写路径仍受 906⑥ 及现有阶段授权约束。

| 项 | 功能及验收条件 |
|---|---|
| 1 方案批准后批量入池 | 显式批准一个固定版本后，整批创建任务、依赖和验收条件。重复批准同一版本返回原批次，异内容冲突拒绝。拒绝循环、缺失依赖及非法范围且整批回滚。只有已具备可验证前置产物的任务可以开工。父批次汇总，联调作为末尾任务。 |
| 2 持久化任务管理器 | 独立任务随时创建。普通任务队尾，加急队首，依赖未满足先等待。原子认领、占额、交接和释放，上限可在 1–3 配置且默认保守，任何时刻禁止第四个有效名额。重启恢复同一任务、同一代执行及原队列顺序。 |
| 3 Playwright FIFO 服务 | 审查请求以任务和轮次为唯一键，按提交顺序由单通道消费；一轮收口后才处理下一轮。重启、响应丢失或可能已发送时按原轮核对和补采，禁止重发。方案讨论和验收保留独立用途和会话绑定。 |
| 4 安全暂停恢复与回收 | 用户加急时确认预计让位任务。让位者保留占额，直到编辑器确认停写、交接持久化且在途对话已收口。新的加急任务接过该名额。因插队安全暂停的任务按顺序恢复，人工暂停或故障挂起按原恢复规则。REWORK 保留原任务。ACCEPTED 且证据落盘后释放名额并回收对应 Agent。 |
| 5 工作台和端到端验收 | 可以新增普通任务、批准方案入池、预览并确认加急，显示占额、依赖阻塞、审查队列和批次进度。隔离环境覆盖方案→并行子任务→FIFO 审查→验收解锁，途中加急、重复请求、进程/响应中断和下游基线绑定。 |

验收证据记录被测完整 SHA、运行环境、命令和退出码。任何实测覆盖缺口保留为独立门禁。
