# 多 Agent 并行派单架构方案 R1（供审查方规划讨论）

- **目标场景（用户 2026-11-21 意图）：** 方案由多步骤组成 → 开多个 agent 各自处理任务 → 每 agent 分别派单交 ChatGPT 处理 → 初级版单任务串行，中级版多任务并行 = 生产力跃升。
- **被测基础：** main `81812dd`（派单整改 c8b3d04 已合入；目标绑定/回执链/发送前拦截/原会话补采链路已经 b-20261121 真实试跑+独立复核验证，DEC-120/121）。
- **性质：** 本方案仅规划讨论，不含实现；通过后另立任务包（参照 b-20261117 模式：规划复审→实现+负例→真实试跑→独立验收）。

## 一、现状硬阻塞（代码事实，2026-11-21 核实）

1. **全局单锁：** `session_lock.mjs` v7 锁路径固定 `runtime/locks/gpt-session.lockfile`（LOCK_PATH_DEFAULT）；但 `acquireSessionLock` **已支持 `opts.lockPath`**（:59）——多锁能力已存在，调用方（gpt_dispatch/各 recoll 驱动）从未传入。冲突 fail-closed 30s 超时退出，无排队。
2. **单浏览器实例：** `DEBUG_PORT=9222`、`PROFILE_DIR=runtime/chrome_profiles/gpt-poc` 为常量（gpt_dispatch.mjs:45-53）；`killProfileChrome` 按 CommandLine 含 `*gpt-poc*` **子串匹配全杀**（:130-137）——多实例场景会误杀其他实例浏览器（实测先例：T2乙 成功关闭浏览器致 T3 首跑 CDP 拒连）。
3. **单写指针：** reviewer 指针单文件；任务腿已全程 `--no-update-pointer`/`--session-result` 绑定（b-20261121 七验不变），审查会话指针保持主会话单写者。

## 二、改造设计（约束：生产默认逐字节不变，注入仅存在于显式调用路径——L-013/deps 经验）

**P1 实例域（instance domain）——核心改动：**
- `gpt_dispatch` 新增 `--instance <ID>`（默认 `default`）：由 ID 派生四件套——
  - `lockPath = runtime/locks/gpt-session-<ID>.lockfile`（经既有 `opts.lockPath` 传入，session_lock.mjs 零改动）；
  - `DEBUG_PORT = 9222 + <instance 偏移>`（配置表或确定性哈希，避免碰撞）；
  - `PROFILE_DIR = runtime/chrome_profiles/gpt-poc-<ID>`（profile 隔离=登录态各自一次）；
  - recoll 驱动同参传递（补采与派单同锁域互斥）。
- **锁域=实例域：** 同实例内任务串行（互斥语义保持不变），跨实例并行。
- `killProfileChrome` 收敛：按本实例 profile 目录**精确匹配**（`*gpt-poc-<ID>*` 边界限定或全串匹配），禁子串通配误杀。

**P2 页所有权：** 独立实例=独立浏览器=独立页空间，tab-hygiene 单实例内逻辑**零改动**；跨实例物理隔离，无需软标记。

**P3 指针与证据：** 任务派单一律绑定/不写指针（已具备）；派单证据目录已有 EEXIST+UUID 后缀保护（c8b3d04），多实例并存不覆盖。

**P4 仓库层（流程级）：** 多 agent 并发=各自任务分支+各自任务包，FIFO 合并；decision-log 追加冲突在合并期人工对齐（编号顺序合并者重排）或预分配编号区间——策略交拍板④。

**P5 M1 登记并发核查（未知项，如实列入）：** `registerArtifactWithRetry` 多实例并发注册安全性未核查过，纳入实现步骤核查项。

## 三、真实并发试跑矩阵（=906⑥ 真实并发实测的具体解锁路径）

| 项 | 构造 | 判据 |
|---|---|---|
| C1 | 双实例并行各派不同会话（一次性非敏感简报） | 双双成功互不干扰；各自回执/归档完整（锁域隔离正例） |
| C2 | 同实例域两进程并发 | 一成功一 fail-closed 锁冲突（互斥保持负例） |
| C3 | 一实例派单成功（触发其 killProfileChrome） | 另一实例在途页/轮次不受影响（隔离正例） |
| C4 | 双实例各自完成回执链+补采闭环 | 复用 b-20261121 证据方法（回执/归属/DOM 审计） |
| C5 | 账号级 429 观察 | **只观察不诱发**（手册纪律）；触发即共享风暴通道全实例退避 |
| C6 | N=2 连续多轮风控观察期 | 无异常后再讨论 N=3 |
