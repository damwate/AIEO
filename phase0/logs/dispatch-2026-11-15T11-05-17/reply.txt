另外补充四项工程要求：

第一，逐条 parent 核验。

不能仅凭 git show 的首末 parent 判断多 commit 链完整性。

第二，区分核验结果。

建议至少有：

PASS：全部规则满足。

FAIL：明确违反规则。

BLOCKED：缺少对象或环境无法完成核验。

不能把无法核验当成 PASS。

第三，断言具体拦截原因。

测试不能只检查 exit code，还必须检查：

指向哪个 commit；

具体错误原因；

是否给出了正确处置建议。

第四，工具自身安全性。

必须验证错误输入、非法路径、异常 Git 输出时不会修改仓库，不会误判通过。
