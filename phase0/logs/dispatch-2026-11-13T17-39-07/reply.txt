二、二进制抽查：接受 Git Blob SHA-1 等效身份核验
建议通过

Git Blob SHA-1 的计算规则：

Python
运行
import hashlib


def git_blob_sha1(data: bytes) -> str:
    header = f"blob {len(data)}\0".encode()
    return hashlib.sha1(header + data).hexdigest()

审查规则：

从指定 commit 的 tree 获取文件对应的 Git Blob SHA-1。

从已通过 TAR 总哈希核验的聚合包中提取对应文件。

本地计算 Git Blob SHA-1。

两者完全一致，认定该文件身份一致。

不一致则判定核验失败，不允许通过文件名、文件大小或其他元数据替代。

这里有一个重要区别：

Git Blob SHA-1 是对象身份核验，不是 SHA-256 意义上的密码学强完整性证明。

因此建议：

TAR 总体完整性继续使用 SHA-256。

每个文件的独立 SHA-256 继续执行 manifest 核验。

Git Blob SHA-1 仅作为 GitHub 无法返回二进制正文时的独立对象身份交叉验证。

不得将 SHA-1 等效核验扩大解释为二进制内容已经被审查者直接读取。
