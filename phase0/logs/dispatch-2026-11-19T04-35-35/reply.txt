二、关键技术裁定

① 修复必须落在 fetch 边界，而不是代理工厂。

推荐：

JavaScript
response = await fetchImpl(url, {
  method: "GET",
  redirect: "manual",
  dispatcher: dispatcher ?? undefined,
  signal: AbortSignal.timeout(config.httpTimeoutMs),
  headers: {
    "user-agent": "aieo-git-pointer-poc/1.0",
    accept: "*/*",
  },
});

理由：

createGitPointerProxyDispatcher() 继续保持无代理返回 null 的既有契约。

fetch 调用边界统一消除 null。

显式注入的有效 dispatcher 原样保留。

使用 ?? 而不是 ||，语义更精确，不把其他 falsy 值一并归一。

即使未来其他调用者显式传入 null，也不会再次触发相同问题。

不推荐修改工厂返回值为 undefined，因为那会改变已有公共函数契约并迫使旧单测改变。
